# v1.16.1 · 旧版最终维护更新

**模型显示**保留原名、npm 包名 `@tzyc/dsh-model-visibility` 和既有配置。本版是旧仓库归档前的最后一个维护版本。只需要聊天菜单显隐、能力来源、受控写回和用量统计的用户可以继续安装和使用，无需切换项目。

## 本版修复

- 不再让存在路由归属歧义的同名模型资料自动放宽附图准入或写入提供商的空白能力字段。资料仍可作为参考；不会改已有的提供商声明。
- 切换 Host 后，不在新连接上重试上一连接的显隐操作。已在途的旧写入不视为回滚。
- 能力目录无法加载或校验面板收起时，已知的批量授权仍可停止。停止只阻止后续派发，不撤销已派发或完成的写入。
- 提供商写入已确认、但本地覆盖清理或回读失败时，保留真实写入回执，并提示刷新核对，不把该情况显示成全部失败。
- 「关于插件」保留旧包版本查询，将原来的 Star 和问题提交入口换成后续项目链接。

## 后续开发

[DSH-The-Model-List](https://github.com/TZYCeng/DSH-The-Model-List) 是独立的后续项目。计划探索多协议转换、上游 thinking 与最终正文的分离，以及可选的响应兼容层。这些功能不在旧版中实现，旧包不会自动切换到新项目。

安装或更新旧包后，请重启 DSH Host 并刷新界面。旧安装包和历史版本仍可从 [GitHub Releases](https://github.com/TZYCeng/dsh-model-visibility/releases) 获取。
