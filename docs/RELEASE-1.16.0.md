# v1.16.0 · 模型菜单、能力来源与思考档位

本次更新把聊天菜单可见性、当前路由档位和资料参考分开，并为写入提供商设置增加逐项回执。

## 主要变化

- **菜单管理**：支持按来源和能力筛选、确认后批量显隐、保留当前会话选择；折叠或筛选不会丢失编辑草稿。修复结构不同的提供商/模型组合可能共用隐藏键的问题。
- **能力来源**：按字段展示声明、公开目录、学习快照和别名等证据。当前对话可选档位与目录参考分开；资料不足不等于不支持。
- **思考档位**：单模型可直接写入兼容提供商；批量填入先预览、再确认。保留已有映射和明确禁用项，协议、路由或写入结果不确定时如实报告。
- **校验与稳定性**：长路由 ID 用批内短编号；缺行只补未通过的目标，最多两组，补答不重做搜索。保留有效的部分结果；区分模型失败和目录读取失败。修复 DSH 宿主上无请求体 GET 路由的 HTTP 400。
- **运维**：增加可开关的本机调试记录、版本与反馈入口，改进 Token 账本读取和 CSV。支持 profile 数据隔离，并保留旧数据文件。

## 升级与验证

安装或更新 **`@tzyc/dsh-model-visibility`** 后，重启 DSH Host 再刷新页面。关闭批量授权不会撤销已经写入提供商的配置；未经确认的预览不写入。

实机一次「公开目录＋校验员补漏」处理 **271/271**，其中 **182 有效、89 未知、0 个模型失败**。Hugging Face 主站超时，镜像读取成功。此结果仅代表这次运行，不保证其他线路或后续目录可用。
